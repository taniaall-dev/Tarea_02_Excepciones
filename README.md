# Java — Tarea 02: Gestión de excepciones

Proyecto de Java de **IT Academy**, centrado en el tratamiento de errores y excepciones, la validación de datos y la organización del código en clases con responsabilidades diferenciadas.

A través de tres niveles de ejercicios, se practican conceptos que permiten desarrollar aplicaciones más robustas y controlar situaciones inesperadas sin interrumpir innecesariamente su ejecución.

## 📚 Contenido del repositorio

### Nivel 1 — Fundamentos de las excepciones

Introducción a la captura y gestión de excepciones estándar de Java, como `InputMismatchException` e `IndexOutOfBoundsException`.

### Nivel 2 — Excepciones personalizadas

Creación y utilización de excepciones propias para representar errores específicos, junto con la validación de entradas y el control de situaciones no válidas.

### Nivel 3 — Gestión de reservas de asientos

Desarrollo de una aplicación de consola para gestionar reservas de asientos de cine, aplicando validaciones, excepciones personalizadas, colecciones y separación de responsabilidades.

## 🛠️ Conceptos trabajados

- Captura y tratamiento de excepciones.
- Excepciones verificadas (*checked*) y no verificadas (*unchecked*).
- Creación y utilización de excepciones personalizadas.
- Validación de entradas del usuario.
- Separación de responsabilidades entre clases.
- Uso de colecciones y métodos reutilizables.
- Aplicación de buenas prácticas de programación.

## 📁 Estructura del proyecto

El repositorio está organizado en tres niveles de ejercicios, ubicados dentro de `src/`. Cada nivel contiene sus propias clases y un README con información sobre los ejercicios correspondientes.

## 🎯 Objetivo

Consolidar los fundamentos del manejo de errores en Java mediante ejercicios progresivos, desde la gestión de excepciones estándar hasta la implementación de una aplicación de reservas con validaciones y excepciones personalizadas.

Cada nivel incluye su propia documentación con la descripción del ejercicio, los conceptos trabajados y las pruebas realizadas.
